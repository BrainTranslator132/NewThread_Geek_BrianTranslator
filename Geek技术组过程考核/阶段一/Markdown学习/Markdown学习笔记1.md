### 1）常用Markdown语法

| 语法     | 写法示例                             | 作用说明                         |
| -------- | ------------------------------------ | -------------------------------- |
| 一级标题 | # 文字                               | 最大号标题，用作文章大标题       |
| 二级标题 | ## 文字                              | 次级标题，用作章节标题           |
| 三级标题 | ### 文字                             | 三级标题，用作小节标题           |
| 加粗     | **文字**                             | 文字加粗，用于强调重点           |
| 斜体     | *文字*                               | 文字倾斜，用于书名、术语等       |
| 行内代码 | `文字`                               | 以代码样式显示，适合命令、文件名 |
| 引用     | > 文字                               | 引用块样式，适合引用资料内容     |
| 无序列表 | - 文字                               | 圆点列表，条目不分先后           |
| 有序列表 | 1. 文字                              | 数字列表，条目按顺序排列         |
| 代码块   | ``` 代码 ```                         | 多行代码区域，自动语法高亮       |
| 表格     | \| 列1 \| 列2 \| 加 \| --- \| --- \| | 生成表格，按 Tab 键跳格快速编辑  |
| 链接     | [文字](网址)                         | 插入可点击的超链接               |
| 图片     | ![说明](图片地址)                    | 插入图片并显示                   |
| 删除线   | ~~文字~~                             | 文字加删除线，表示已废弃内容     |
| 分割线   | ---                                  | 插入水平分割线，分隔不同内容     |
