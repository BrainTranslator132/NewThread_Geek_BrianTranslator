### Q2: GitHub 是干什么的？ Pull Request、Fork 这些词你是怎么理解的，又是从哪里学到的？
> #### A2.1:GitHub是一个基于Git的分布式版本控制和协作代码托管平台。
> - 版本管理？
>   - 对象：人（不同开发者）、计算机（本地、服务器）、软件
>   - 时间管理：历史版本
>   - 多人间版本管理：
> - 基于Git？
> 	- 分布式版本控制工具，记录修改历史
> - 分布式版本控制
>   - 所有人计算机版本库地位平等，树状记录历史版本与同源版本，可对分支进行合并
>   - 参考文献：[通俗易懂分布式版本控制 Git_分布式服务器用什么版本控制器-CSDN博客](https://blog.csdn.net/kele_baba/article/details/119768934)
>  - 协作代码托管平台？
>  	- git的云代码仓库（将git的本地版本管理在云端服务器模拟）
> #### A2.2: 基于以上内容，可知，在git中，
>  - Pull Request:将本地分支子版本推送给父版本请求合并 
>  - Clone:接收其他云仓库的版本库于本地计算机仓库
>  - Fork:接收其他云仓库的版本库于自己云仓库
>  - 参考文献：[Git核心概念解析：Fork、Clone与Branch的区别与应用_github fork-CSDN博客](https://blog.csdn.net/misstianyun/article/details/143871511)
